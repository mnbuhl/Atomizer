## Cross-Phase Integration

All 12 confirmed connections wired. One behavioral warning:

- **`queue` parameter unused in `EntityFrameworkCoreStorage.ExecuteInLeaseAsync`** — EF Core uses a single connection-scoped `ReadCommitted` transaction rather than per-queue locking. InMemory uses per-queue `SemaphoreSlim`. The stated contract ("exclusive lease for the given queue") is only fully met by the InMemory backend. Not a correctness bug for the current single-DbContext use pattern, but a behavioral divergence to be aware of.
