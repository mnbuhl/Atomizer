# Milestone v1.0: Storage Refactor

**Status:** ✅ SHIPPED 2026-05-03
**Phases:** 1–5
**Total Plans:** 17

## Overview

This milestone refactored the Atomizer storage layer from a separate leasing-scope abstraction to a unified callback-based `ExecuteInLeaseAsync` contract. The work proceeded in strict dependency order: define the contract, validate it on the simpler InMemory backend, extract provider SQL into dialect classes, then implement the full EF Core backend with atomic acquisition and native per-provider upsert. The milestone closed by removing all deprecated types and completing XML documentation.

## Milestone Summary

**Key Decisions:**

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Callback-based leasing (`ExecuteInLeaseAsync`) | Transaction must span GetDueJobs + UpdateJobs; separate acquire/release allows double-dispatch | ✓ Implemented — Phase 1 |
| InMemory fully aligns to EF Core contract | Diverging behavior between backends makes integration tests misleading | ✓ Implemented — Phase 2 |
| `ISqlDialect` strategy pattern (internal) | Raw SQL scattered; dialect classes make adding providers safe and testable | ✓ Implemented — Phase 3 |
| Native upsert per-provider | EF Core no native upsert; provider SQL already the established pattern | ✓ Implemented — Phase 4 |
| COMPAT-02 dropped (no version bump) | Project will not publish to NuGet this milestone | Dropped — 2026-05-03 |

**Tech Debt Deferred:**

- InMemoryStorage `_schedules` dictionary not protected by scheduler lock in GetDueSchedulesAsync / UpdateSchedulesAsync (CR-03, CR-04)
- InsertAsync missing idempotency key check in InMemoryStorage (CR-01)
- `queue` parameter unused in `EntityFrameworkCoreStorage.ExecuteInLeaseAsync` — no per-queue DB isolation
- Integration tests (EF Core) require Docker/Testcontainers — runtime verification deferred

**Issues Resolved:**

- Eliminated `@todo` race condition in `UpsertScheduleAsync` (check-then-insert → atomic per-provider upsert)
- Eliminated double-dispatch structural risk in job acquisition
- Removed `IDatabaseProviderSql` public interface (replaced with `internal ISqlDialect`)
