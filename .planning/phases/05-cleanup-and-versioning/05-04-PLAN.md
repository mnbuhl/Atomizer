<!-- CS1591 fix protocol -->

When dotnet build reports CS1591 errors, each error looks like:
  error CS1591: Missing XML comment for publicly visible type or member 'TypeName.MemberName'

For each CS1591 error:
1. Identify the file from the error path.
2. Read the file to see the member.
3. Add `/// <summary>Brief description.</summary>` (and `<param>`/`<returns>` as needed)
   immediately above the member declaration.
4. Re-run the build to confirm the error is cleared.

Doc style rules (same as plans 02 and 03):
- One sentence ending with a period.
- `<param>` for every parameter.
- `<returns>` for non-void.
- `<remarks>` nested inside `<summary>`.
- No `<exception>` tags.
- Match the parameter name exactly as declared in the method signature.

Common residual CS1591 sources (things plans 02/03 might have missed):
- QueueOptions constructor `QueueOptions(QueueKey queueKey)` — may lack docs.
- QueueOptions.QueueKey property `public QueueKey QueueKey { get; private set; }` — check.
- QueueOptions.TickInterval property — check.
- SchedulingOptions.TickInterval property — check.
- Any `public` method or property in a documented class that was overlooked.
- The `WorkerId` value object is `internal sealed` — no docs needed, skip any CS1591 for it.

QueueOptions constructor suggested text:
/// <summary>
/// Initializes a new <see cref="QueueOptions"/> with the specified queue key.
/// </summary>
/// <param name="queueKey">The queue key identifying this queue.</param>

QueueOptions.TickInterval suggested text:
/// <summary>
/// Gets the interval at which the internal processing loop ticks.
/// <remarks>Default is 1 second.</remarks>
/// </summary>

SchedulingOptions.TickInterval suggested text:
/// <summary>
/// Gets the interval at which the internal scheduling loop ticks.
/// <remarks>Default is 1 second.</remarks>
/// </summary>
