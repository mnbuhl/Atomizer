<objective>
Replace `MigrateAsync()` with `EnsureCreatedAsync()` in the test fixture base class, and delete all migration folders and DesignTime factory classes from the test project. Testcontainers always starts a fresh database — no migration history exists to conflict, so `EnsureCreatedAsync` creates the schema directly from the EF model (which will include the unique index on JobKey added in Plan 01).

Purpose: The unique index on JobKey (Plan 01) cannot be added to the existing migrations without generating a new migration file. Deleting migrations and using `EnsureCreatedAsync` removes this coupling entirely — the schema always matches the current EF model.

Output: Clean test project with no migration files; fixture uses `EnsureCreatedAsync`; build passes.
</objective>
